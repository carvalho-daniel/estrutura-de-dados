# Estrutura de Dados

 Exercícios desenvolvidos durante a matéria de Estruturas de Dados I, no curso de Sistemas de Informação pelo IF Sudeste MG Campus Manhuaçu 

## Temas abordados
* Recursividade
* Analise assintótica de algoritmos
* Operações com vetores
* Lista
* Pilhas
* Filas
* Árvores binárias
* Métodos de ordenação n² (Bubble Sort, Selection Sort, Insertion Sort)
